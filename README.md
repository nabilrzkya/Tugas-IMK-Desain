# Desain Antarmuka Website Penjualan Makanan

Tugas Desain Antarmuka Website E-Commerce Kuliner berdasarkan materi "Prinsip_Dasar_Desain_Interaksi.pdf".

## Penerapan Prinsip Desain pada Website Makanan:
1. **Grouping & Structure:** Menu makanan dikelompokkan berdasarkan kategori (Makanan Utama, Minuman, Camilan) menggunakan kotak-kotak pembatas agar rapi.
2. **Alignment:** Nama menu menggunakan rata kiri (align left) supaya mudah dibaca, sedangkan harga menggunakan rata kanan (right align) agar angka ribuan sejajar secara visual.
3. **Affordances:** Tombol "Pesan Sekarang" dibuat menonjol berbentuk tombol fisik yang intuitif untuk diklik. Untuk pilihan topping menggunakan checkbox dan level pedas menggunakan radio button.
4. **Safety & Protection:** Menyediakan tombol pembatalan (Undo) jika pengguna tidak sengaja menghapus item dari keranjang belanja.
